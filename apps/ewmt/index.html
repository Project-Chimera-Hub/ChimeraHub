Difficulty

How often a trial repeats the item it should be compared with.

How often a non-match is a lure: the item from one step nearer or further back. At 0%, recent items only repeat when there aren’t enough to go round.

Each trial asks for a random k from the floor up to n, shown just above the grid.

Mistake sound

Plays when you miss a match or answer one that wasn’t there. The next trial waits for it to finish, so it never covers a word.

Words

    Import adds every word in a plain text file (.txt). A space or a line break separates one word from the next, so a file containing yo wassup (or wassup yo) adds “yo” and “wassup”. Punctuation at the start or end of a word is left off, and words already in the list are skipped. You can also drop text files onto this panel.
